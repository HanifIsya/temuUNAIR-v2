# @temuunair/contracts

Single source of truth for the TemuUNAIR API contract: Zod schemas (`src/enums.ts`, `src/common.ts`,
`src/errors.ts`), the route registry (`src/registry.ts`) and per-route examples (`src/examples.ts`).
Everything derived — `docs/04-contracts/backend/BE-02-openapi.yaml`,
`packages/contracts/generated/types.ts`, `packages/contracts/generated/client.ts` and
`packages/contracts/generated/msw-handlers.ts` — is generated by `pnpm contracts:build` and must
never be hand-edited; `pnpm contracts:check` fails on drift (docs/04-contracts/README.md).

Use `pnpm contracts:build` to regenerate the four artefacts, `pnpm contracts:check` for drift,
`pnpm contracts:lint` for the BE-01 rules (`src/lint.ts`) and `pnpm contracts:breaking` to compare
against the baseline on `origin/main` (`src/breaking.ts`; override with `CONTRACTS_BASELINE_DIR`).
Add or change endpoints by editing `src/registry.ts` plus `src/examples.ts` in a `TMU-CTR-*`
contract task — never in a feature PR — then rebuild and commit the generated output.
